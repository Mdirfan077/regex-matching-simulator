Pattern Rules
Symbol Meaning
A–Z Matches exactly that one character
+ One or more of the preceding character
Examples
A+B → one or more A, then B
AB → exactly A then B
⚠ Invalid: +AB (starts with +), A++B (double +), AB+ (ends with +)
Complexity
Time
O(n·m)
n = string, m = pattern
Space
O(1)
No extra data structures
How it works
The algorithm scans the pattern left→right. For each token it checks if the current string position matches. The + operator greedily consumes all consecutive matching characters. The match succeeds only if the entire string is consumed.

Algorithm Explained
01
Validate Inputs
Check that the string contains only A–Z, and the pattern has no invalid syntax like + at start, double ++, or trailing +.
02
Tokenize Pattern
Break pattern into tokens: either exact (e.g. B) or plus (e.g. A+). Each token describes what to consume from the string.
03
Match Tokens
For exact tokens: consume one character. For plus tokens: consume one or more of that character greedily. Fail if the expected character isn't there.
04
Full Coverage Check
After all tokens are matched, check that the string has been fully consumed. If any characters remain, it's a FALSE — the pattern didn't cover the whole string.
